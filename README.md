# Raid Marker Helper

Petite application web mobile destinée à faciliter la préparation et le suivi pendant les raids et donjons Mythic+.

## Fonctions

### Raid Marker

Pense-bête rapide pour mémoriser des séquences de marqueurs pendant un combat.

- affichage instantané des marqueurs saisis ;
- support de 4 ou 8 marqueurs ;
- interface adaptée au mobile ;
- installation comme PWA ;
- fonctionnement hors ligne ;
- écran maintenu actif pendant l'utilisation.

### Loot Tracker

Liste de suivi des équipements BIS à récupérer pour plusieurs personnages.

- gestion de plusieurs personnages ;
- sélection des joueurs suivis ;
- affichage des besoins :
  - par contenu (donjon / raid / autres) ;
  - par joueur ;
- affichage du slot et des notes associés aux objets ;
- statistiques des loots disponibles par personnage ;
- totaux par personnage ;
- suivi des objets acquis individuellement pour chaque personnage ;
- sauvegarde locale du suivi.

### Mythic+ Helper

Pense-bête pour les donjons de la saison Mythic+.

- sélection du donjon ;
- découpage en sections :
  - trash ;
  - boss ;
  - autres étapes importantes ;
- navigation rapide entre les différentes sections ;
- informations générales par zone ;
- fiches détaillées des mobs ;
- identification des mobs prioritaires ;
- liste des capacités importantes ;
- catégorisation des capacités (AoE, cône, dégâts, heal, DoT, soak, enrage...) ;
- indication explicite de l'action à effectuer (Kick, Dodge, CD Def, Focus, etc.) ;
- mise en évidence des actions prioritaires ;
- notes complémentaires sur les mobs et les capacités ;
- support d'icônes pour les capacités ;
- interface pensée pour une consultation rapide sur téléphone ;
- écran maintenu actif pendant l'utilisation.

## Utilisation

Application prévue pour un usage personnel en raid et en donjon Mythic+.

Les données (personnages, contenus, loots et informations des donjons) sont stockées localement ou fournies par les fichiers JSON de l'application.

L'application est conçue pour fonctionner comme une PWA et rester utilisable hors ligne une fois les ressources mises en cache.
